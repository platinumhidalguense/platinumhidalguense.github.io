# Corregir un importe de cheque

El administrador y la contadora con permiso de cheques pueden abrir un cheque **PENDIENTE**, sin número ni consecutivo, y pulsar **Corregir importe manualmente**.

Captura el importe correcto y el motivo, y confirma el cambio. Quedan registrados el importe anterior, el nuevo, el usuario y la fecha. El listado se actualiza al confirmar la respuesta del servidor.

La opción no admite cheques expedidos, entregados, cancelados, eliminados, con folios capturados, entrega registrada o pagos vinculados. Si otro usuario cambia el cheque durante la captura, se pide abrirlo otra vez.

Al abrir un pendiente se conserva su importe guardado. **Verificar neto** permite consultar y adoptar el importe de NOI o recibo de esa persona y periodo. Si el importe difiere, guardar avisa y no lo sustituye silenciosamente. Antes de expedir siguen aplicándose las verificaciones existentes; corregir la captura no modifica los cálculos ni los cierres de nómina.
